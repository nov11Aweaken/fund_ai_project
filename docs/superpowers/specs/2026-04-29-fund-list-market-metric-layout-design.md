# 基金列表行情指标布局重设计

## 背景

基金列表卡片右侧当前同时展示“当日估值变化”和“上一交易日净值变化”。两项数据都带有红绿涨跌语义，且位置过近，容易在一个很小的视觉区域内形成颜色竞争，影响清爽度与主次关系。

本次设计目标不是增加信息，而是在**尽量不增加卡片高度**的前提下，重新安排两项指标的位置关系与视觉层级，让用户一眼看出：

1. 当日估值变化是主信息。
2. 上一交易日净值变化是辅助对照信息。
3. 两者都保留涨跌语义，但不会互相抢视觉注意力。

## 目标

- 保持基金列表卡片整体紧凑，不明显增加高度。
- 保留两项指标的同时，减少相邻强色块带来的拥挤感。
- 强化“主值 / 次值”层级，而不是让两项数据看起来同权重。
- 仅调整基金列表卡片行情区域，不影响排序、数据计算、其他页面或其他指标模块。

## 非目标

- 不修改基金数据抓取、估值计算或上一交易日净值变化的算法。
- 不修改基金详情页、市场页或其他卡片布局。
- 不新增新的行情指标，也不改变现有排序字段含义。

## 已比较方案

### 方案 A：左右分离

- 把上一交易日净值变化移到卡片左侧次信息区。
- 当日估值变化保留在右侧主视觉位。

优点是颜色距离最远、最干净；缺点是信息被拆到两侧，行情对照关系减弱。

### 方案 B：上下折叠

- 两项信息继续放在右侧。
- 主值在上，上一交易日净值变化缩成下方次行。

优点是改动最小；缺点是两种颜色仍在同一小块区域上下堆叠，改善有限。

### 方案 C：单行对照

- 两项信息继续位于右侧。
- 上一交易日净值变化放在左，当日估值变化放在右，同一行展示。
- 通过字号、字重、留白来拉开主次关系。

该方案在“紧凑度”和“视觉干净度”之间最平衡，因此被选定。

## 最终设计

### 1. 布局结构

采用**右侧单行对照布局**：

- 右侧行情区域继续作为卡片的数值焦点区域。
- “上一交易日净值变化”放在主值左侧，作为次指标。
- “当日估值变化”放在最右侧，作为主指标。

推荐阅读顺序为：

`昨净 -0.63%    +1.28%`

其中左侧是辅助对照，右侧是主值结论。

### 2. 层级规则

#### 主指标：当日估值变化

- 保持当前主值定位。
- 继续使用最大字号和最高字重。
- 保持现有红绿涨跌色语义。

#### 次指标：上一交易日净值变化

- 放在主指标左侧。
- 标签使用中性色。
- 数值继续保留红绿语义，但整体视觉强度降低一档。
- 字号与字重都低于主指标，避免与主指标竞争。

### 3. 文案规则

为了适应紧凑布局，上一交易日净值变化的标签文案固定为：

- `昨净`

不使用完整长文案，以免右侧单行过长、压缩主值空间。

### 4. 间距与分隔

- 先优先使用**留白间距**拉开两项指标。
- 默认不强制加入显性粗分隔线。
- 如实际界面仍显拥挤，可再考虑加入非常轻的细分隔线或分隔点，但这属于次优补充，不作为首选。

### 5. 颜色策略

- 两项指标都保留涨跌红绿语义。
- 但上一交易日净值变化应使用**弱化一档的红绿表现**，让视觉焦点始终落在当日估值变化上。
- 实现阶段优先采用“复用现有涨跌色语义、降低字重与视觉存在感”的方式，而不是重新引入一套全新颜色体系。
- 若值为 `0.00%`，保持中性色。

## 组件与实现边界

本次改动只涉及基金列表卡片的行情区域展示契约，不改变数据来源。

预期实现边界如下：

- 调整 `main.py` 中基金列表卡片右侧行情区域的排布方式。
- 在现有行情指标结构上补充适用于“主值 / 次值单行对照”的展示字段。
- 复用当前已存在的涨跌颜色语义与百分比格式化逻辑。

不需要新增独立页面组件，也不需要拆分新的数据模型文件。

## 数据流影响

- 输入数据仍沿用现有的 `est_pct` 与 `prev_day_pct`。
- `_build_fund_overview_metrics()` 继续作为基金列表卡片行情展示的装配点。
- UI 渲染层只重排展示顺序与样式层级，不改变数值本身。

## 错误与空值处理

- 当 `est_pct` 缺失时，主指标仍显示 `--`，并保持当前降级风格。
- 当 `prev_day_pct` 缺失时，次指标显示 `--`，但不破坏单行整体布局。
- 当 `prev_day_pct == 0` 时，使用中性色，不触发红绿强调。

## 测试要求

实现阶段至少需要补充或更新以下验证：

1. 基金列表行情指标构造结果应能表达：
   - 主指标文本
   - 次指标标签文本
   - 次指标数值文本
   - 次指标颜色语义
2. 当 `prev_day_pct` 为正、负、零时，次指标颜色行为符合设计。
3. 不影响现有基金列表排序说明与其他行情指标块测试。

## 验收标准

- 基金列表卡片高度与当前版本接近，没有明显增高。
- 用户在右侧一眼可见主值是“当日估值变化”。
- 上一交易日净值变化仍可快速读取，但明显是辅助信息。
- 两项红绿语义不会像当前版本一样在相近区域形成明显拥挤感。
