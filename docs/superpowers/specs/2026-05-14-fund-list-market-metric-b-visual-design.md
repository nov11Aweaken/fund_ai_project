# 基金列表行情区 B 版主值卡片化设计

## 背景

当前基金列表右侧行情区已经完成“昨净组内紧凑、与主值拉开”的分组留白优化，但视觉上仍偏功能性排布：虽然信息关系更清楚了，整体仍像两组数字并排，缺少一个足够明确的视觉焦点。

在已展示的多种 HTML 方案中，用户选择了 **B 版**。这个方向的核心不是继续拉开间距，而是把“今日估值涨跌幅”从普通文本提升为一个独立的主视觉对象。

## 目标

- 保持基金列表卡片整体紧凑，不明显增加高度。
- 让“今日估值涨跌幅”成为右侧行情区的第一视觉焦点。
- 让“昨净”继续保留红绿语义，但退回辅助信息层。
- 在不增加噪声感的前提下，提升基金列表的整体设计感。

## 非目标

- 不修改 `est_pct`、`prev_day_pct` 的数据来源或计算逻辑。
- 不调整基金详情页、市场页或其他卡片区域。
- 不引入新的行情字段、徽章体系或动画效果。
- 不把行情区改成两行或明显增高卡片。

## 已比较方案

### 方案 A：极简分组

- 延续当前单行框架。
- 通过更大的组间距强化“昨净组”和主值的分隔。

优点是克制、稳妥；缺点是主值虽然更清楚，但仍然只是“一段更大的文本”。

### 方案 B：主值卡片化

- 保持单行结构。
- 左侧仍是普通文本样式的 `昨净 -0.63%`。
- 右侧把今日估值主值放入轻胶囊容器中，成为明确的主视觉焦点。

该方案在“强化重点”和“保持简洁”之间最平衡，因此被选定。

### 方案 C：上下双层

- 今日估值在上方单独突出。
- 昨净退到下方说明层。

优点是秩序非常明确；缺点是会拉高卡片，不符合当前紧凑目标。

### 方案 D：行情条

- 通过横向状态条增强产品感与行情终端感。

优点是风格鲜明；缺点是会改变现有产品气质过多，容易喧宾夺主。

## 最终设计

### 1. 布局结构

采用 **“辅助文本 + 主值轻胶囊”单行布局**：

- 左侧仍为 `昨净 -0.63%` 的普通文本组。
- 右侧将今日估值主值渲染为轻胶囊样式。
- 视觉阅读顺序保持为：先扫到右侧主值，再回读左侧辅助说明。

推荐视觉结构：

`昨净 -0.63%     [ +1.28% ]`

其中：
- 左侧是说明信息
- 右侧胶囊是结论信息

### 2. 主值胶囊规则

今日估值主值胶囊采用 **轻胶囊**，不是重色块卡片：

- 使用低饱和浅底色
- 保留轻边框
- 圆角明显，但不过度夸张
- 内边距略大于普通文本，形成独立视觉对象
- 文本仍使用当前的红绿涨跌语义

具体气质目标：

- 比纯文本更有“主角感”
- 比按钮/标签更克制
- 不要做成很厚重、很高饱和的药丸按钮

### 3. 昨净规则

“昨净”继续保留为辅助信息：

- 标签灰色
- 数值保留红绿语义
- 仍然保持普通文本样式
- 不进入胶囊，不和主值争同一视觉层级

### 4. 间距与层级

- 左侧 `昨净` 组内部继续保持紧凑
- `昨净` 组与主值胶囊之间保留明确间距
- 即使主值进入胶囊，也不应让右侧显得拥挤
- 胶囊不应使整张卡片明显增高

### 5. 颜色策略

- 今日估值主值：继续使用现有涨跌红绿语义
- 主值胶囊底色：使用低饱和浅色背景，随正负值切换为对应倾向色
- 昨净数值：继续复用现有红绿语义，不新增新颜色体系
- 零值仍保持中性色

### 6. 空值处理

- 当 `est_pct` 缺失时，主值仍显示 `--`
- 若主值进入胶囊，`--` 也保持胶囊结构，避免布局跳动
- 当 `prev_day_pct` 缺失时，左侧仍显示 `昨净 --`

## 组件与实现边界

本次改动只涉及基金列表右侧行情区样式层。

预期实现边界如下：

- 调整 `_build_fund_list_market_row()` 的返回结构
- 为主值胶囊补充轻量样式
- 保持 `_build_fund_overview_metrics()` 的数据契约不变
- 不要求改动其他卡片区域

## 数据流影响

- 输入数据仍沿用现有 `est_pct` 与 `prev_day_pct`
- `_build_fund_overview_metrics()` 继续提供主值、昨净值与颜色语义
- UI 渲染层负责把主值包装为轻胶囊

## 测试要求

实现阶段至少应补充或更新以下验证：

1. `_build_fund_list_market_row()` 仍保留左侧昨净组
2. 主值从普通文本改为胶囊容器结构
3. 胶囊内主值文本仍保留现有颜色语义
4. `est_pct` 缺失时，胶囊结构和 `--` 占位仍稳定
5. 不影响现有 `昨净` 文案、颜色语义与基金列表其他测试

## 验收标准

- 用户第一眼注意力先落在今日估值主值上
- “昨净”仍可快速读取，但明显退为辅助层
- 卡片高度与当前版本接近，没有明显增高
- 整体比当前版本更有设计感，但不显得厚重或花哨
