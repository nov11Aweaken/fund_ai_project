# 基金详情卡片紧凑表格化设计

## 背景

当前基金详情界面中的 **“收益区间”** 和 **“均线与位置”** 两张卡片，仍沿用通用指标 tile 的排法：每个指标单独占一块小卡片，信息层级清楚，但对于短周期收益和多条均线这类需要“横向对比”的数据来说，阅读路径偏散，单位面积内的信息密度也不高。

用户希望对这两张卡片做一次 **收紧优化**，让其中的数据改用更紧凑、更像表格的小型数据面板来排列，同时继续保持当前详情页的整体卡片气质，不做明显增高或过度终端化的改造。

在已展示的多种 HTML 方案中，用户选择了 **A 版**，并进一步明确：**表格中的方向型数值需要保留红绿语义。**

## 目标

- 让“收益区间”和“均线与位置”两张卡片内部排布更紧凑。
- 让同类指标更容易横向扫读与比较。
- 保持当前详情页卡片风格，不引入明显割裂的新视觉体系。
- 为有方向语义的数值补上明确的红绿显示。
- 控制卡片高度，不因为表格化而明显膨胀。

## 非目标

- 不调整基金详情页外部整体布局。
- 不修改收益区间、均线、估值分位的数据来源或计算逻辑。
- 不新增新的技术指标、排序行为、交互控件或动画。
- 不把详情区改造成重度终端式大表格。
- 不影响“持仓概览”卡片，除非实现上需要复用极小的公共辅助布局。

## 已比较方案

### 方案 A：卡片内双列表格

- 保留当前卡片外壳与标题区。
- 将卡片内部从多个 tile 改成紧凑表格行。
- 左侧显示指标标签，中间显示辅助说明，右侧显示主值。

优点是最稳妥、最贴合当前产品气质，因此被选定。

### 方案 B：紧凑数据面板

- “收益区间”改为 2×2 小矩阵。
- “均线与位置”保留表格，但整体更像数据终端。

优点是信息密度更高；缺点是卡片气质更偏面板化，改动感更强。

### 方案 C：超紧凑矩阵表

- 两张卡片都改成更强表格感的矩阵。
- 强化列头、网格和数据终端感。

优点是最紧凑；缺点是和当前详情页风格差异最大。

## 最终设计

### 1. 总体布局方向

两张卡片继续保留当前外层卡片结构：

- 标题
- 副标题
- 卡片内部内容区

仅将内容区从当前的 **tile 栅格** 调整为 **紧凑三列表格行**。

推荐视觉结构：

```text
收益区间
近3日   短线表现      +1.82%
近7日   一周趋势      +3.46%
近15日  半月趋势      -0.88%
近30日  月度表现      +5.12%
```

```text
均线与位置
估值分位  近历史区间   62.4%
MA5      偏离 +1.18%   1.4832
MA10     偏离 +2.06%   1.4726
MA20     偏离 -0.52%   1.4918
MA250    偏离 +8.34%   1.3865
```

### 2. 收益区间卡片规则

“收益区间”卡片改为 4 行紧凑表格：

- 左列：周期标签（近3日 / 近7日 / 近15日 / 近30日）
- 中列：辅助说明（短线表现 / 一周趋势 / 半月趋势 / 月度表现）
- 右列：收益值

样式规则：

- 标签列使用灰色中性文本
- 中间说明列弱化一级，字号略小
- 右侧收益值右对齐
- 收益值保留单独的红 / 绿 / 中性语义
- 数值使用等宽数字排布，便于纵向比较

### 3. 均线与位置卡片规则

“均线与位置”卡片改为 5 行紧凑表格：

- 左列：项目标签（估值分位 / MA5 / MA10 / MA20 / MA250）
- 中列：辅助说明（近历史区间 / 偏离 +x.xx% / 偏离 -x.xx%）
- 右列：主值（分位值或均线值）

样式规则：

- `估值分位` 属于位置型指标，右侧主值保持中性色
- `MA5 / MA10 / MA20 / MA250` 的右侧主值，跟随对应偏离值的方向语义着色
- 中间“偏离”说明文本也同步使用对应方向色
- 右侧主值保持右对齐和等宽数字

### 4. 红绿语义规则

方向型数值采用统一语义：

- 正值：红色
- 负值：绿色
- 零值：中性色

具体适用范围：

- “收益区间”中的收益值：使用红 / 绿 / 中性
- “均线与位置”中的偏离说明：使用红 / 绿 / 中性
- “均线与位置”中的 MA 主值：跟随偏离说明的红 / 绿 / 中性
- “估值分位”主值：保持中性，不强行套红绿

### 5. 紧凑度与间距规则

- 行高应明显小于当前 tile 栅格
- 行与行之间使用极轻分隔或留白，不做重表格边框
- 三列之间留出明确列距，但整体仍需收紧
- 卡片标题区维持当前节奏，不做额外压缩
- 卡片整体高度应低于当前版本，或至少视觉上更紧凑
- 以当前详情卡片高度为基线对比，不接受明显增高

### 6. 空值与异常值处理

- 任何缺失值仍显示 `--`
- `--` 使用中性色
- 当方向值缺失时，不显示伪红绿
- 当均线主值存在、偏离值缺失时，主值回退为中性色
- 表格结构在空值情况下保持稳定，避免列宽跳动

## 组件与实现边界

本次改动只涉及基金详情页的两组指标卡内容区：

- “收益区间”
- “均线与位置”

预期实现边界如下：

- 调整详情页这两组 metric 的渲染方式
- 允许新增面向详情页紧凑表格的局部辅助函数
- 可以继续保留当前数据构造函数，但需要补充更适合表格渲染的字段
- 不要求改动市场页、基金列表页或图表区域

## 数据流影响

- 继续复用现有 `_build_fund_detail_return_metrics()` 与 `_build_fund_detail_ma_metrics()` 的数据来源
- 如有必要，可让这两个 helper 返回更明确的 `label / value / subtitle / color` 组合，或补充表格渲染所需字段
- UI 层负责把这些数据渲染为紧凑表格，而不是复用当前 tile 栅格

## 测试要求

实现阶段至少应补充或更新以下验证：

1. “收益区间”卡片不再使用当前 4 张独立 tile 排布
2. “均线与位置”卡片不再使用当前 5 张独立 tile 排布
3. 表格行的标签、说明、主值顺序稳定
4. “收益区间”中的收益值保留红绿语义
5. “均线与位置”中的 MA 主值会跟随偏离方向着色
6. “估值分位”仍保持中性色
7. 空值情况下仍显示 `--`，且表格结构稳定
8. 不影响基金详情页其他卡片与图表测试

## 验收标准

- 用户能明显感知到两张卡片比当前版本更紧凑
- 同类数据的横向比较更顺手，不再像分散的小卡片
- 红绿语义在方向型数值上更直观
- 整体仍像当前产品的一部分，而不是外接一块“终端表格”
- 详情页整体高度和节奏没有被明显破坏
